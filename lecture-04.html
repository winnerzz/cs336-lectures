第 4 讲 Attention Alternatives & MoE

预计用时： 90-150 分钟

一句话： 标准注意力随上下文长度平方级变贵，标准 FFN 想变强就得加参数、加算力。这一讲讲两条”绕开”的路：① 线性注意力 / Mamba（把平方降成线性）；② MoE 专家混合（加参数但不加算力）。

提示： 难度：概念为主、数学偏多但不吃 GPU。是 L03 的延伸、和 L10 衔接。零基础抓住”为什么要这么做”即可，递推公式看不懂可跳过。

前置知识：这一讲默认你已经会（我从 0 给你补）

这一讲是在”改进/替代注意力”，所以默认你已经懂注意力机制本身和一点更老的序列模型。从 0 补上：

  • 注意力 (attention)：本讲的出发点。如果还不熟（Q/K/V、softmax 那套），先看 L03 的前置板块，那里从 0 讲了。
  • 平方复杂度从哪来：注意力要算”每个 token 对每个 token”的关系，n 个 token 就有 n×n 对 → 序列越长越贵（n²）。这一讲的”线性注意力”就是想把 n² 降到 n。
  • RNN（循环神经网络）：Transformer 之前的主流序列模型。它一个 token 一个 token 地往前走，维护一个”状态 S”，每读一个词就更新 S。本讲的关键洞见是”线性注意力其实能写成 RNN 形式”——所以你得先知道 RNN 长这样。
  • 矩阵乘法结合律：(A·B)·C = A·(B·C)，换个加括号的顺序，结果一样但计算量可能差很多。线性注意力的”魔法”就是把 (Q·Kᵀ)·V 换成 Q·(Kᵀ·V)。矩阵维度规则见 L02 前置板块。
  • 表达力 (expressiveness)：模型能表示多复杂的函数。“门控让线性注意力更有表达力”就是说它能学更复杂的东西。

先补几个词（零基础向）

  • 注意力的平方复杂度：标准注意力要算”每个 token 和每个 token”的关系，n 个 token 就是 n² 对 → 上下文越长越贵。
  • 线性注意力 (linear attention)：换一种算法把 n² 降到 n（线性）。
  • RNN（循环网络）：一种”一步步往前、维护一个状态 S”的老式序列模型。线性注意力恰好能写成 RNN 形式——这点很关键。
  • Mamba / 状态空间模型 (SSM)：线性注意力的强化版，给状态加”门控”，又快又强。
  • gating（门控）：用一个学出来的小闸门控制”让多少信息通过/擦除”，是本讲反复出现的好东西。
  • MoE (Mixture of Experts，专家混合)：把一个大 FFN 换成很多个 FFN（专家）+ 一个路由器，每个 token 只走其中几个专家。
  • router / routing（路由）：决定”这个 token 交给哪几个专家”的选择器，通常是”选 top-k 个”。
  • sparse（稀疏）：每次只激活一小部分参数（不是全部都算），这是 MoE 省算力的核心。

学完你能

  1. 理解线性注意力的”重排技巧”为什么能把 n² 降成 n，以及它和 RNN 的对偶。
  2. 了解 Mamba-2 / Gated Delta Net 如何用门控让线性注意力更强。
  3. 理解 MoE 是什么、为什么流行、训练难在哪（路由不可导、负载均衡）。

第一部分：注意力替代方案

线性注意力：一个”换括号”的魔法

标准注意力（softmax 去掉时）是 (Q·Kᵀ)·V，先算 Q·Kᵀ 是 n×n，平方级。但矩阵乘法可以换结合顺序：

(Q·Kᵀ)·V  =  Q·(Kᵀ·V)

为什么这一步省这么多？ 左边先算 Q·Kᵀ 得到 n×n 矩阵，代价 ~n²。右边先算 Kᵀ·V 得到一个 d×d 的小矩阵（和 n 无关！），再乘 Q，总代价 ~n。从平方降到线性。代价是去掉了 softmax 那层非线性，所以叫”线性”注意力。

和 RNN 的对偶（最妙的点）

线性注意力可以写成一步步递推：Sₜ = Sₜ₋₁ + kₜvₜᵀ，yₜ = qₜᵀSₜ。这正是 RNN 的形式——维护一个状态 S，每来一个 token 就更新。

这个”对偶”为什么重要？ 同一个模型有两副面孔：训练时用并行的平方形式（喂全序列，快）；推理时用串行的线性形式（一步步生成，状态 S 固定大小，不像 KV cache 那样随长度涨）。鱼和熊掌兼得。

Mamba-2 / Gated Delta Net：加门控

给递推加上”门” γₜ（甚至”擦除”门 βₜ），让状态能选择性记住/遗忘： - Mamba-2：Sₜ = γₜSₜ₋₁ + kₜvₜᵀ，γₜ 由输入算出。 - Gated Delta Net：再加一个”按当前 key 方向擦除旧状态”的项。

一句话：门控让线性注意力更有表达力，同时保住”训练并行/推理线性”的对偶性质。Nemotron、Qwen 3.5 等用 3:1 或 7:1 的”混合”（几层线性 + 一层全注意力），性能不输、长上下文更省。

另一条路：稀疏注意力（DSA）

不换算法，而是只关注一部分 token（如 DeepSeek Sparse Attention），用一个轻量”索引器”挑出重要的，甚至能在普通预训练后再”事后”加上。

第二部分：Mixture of Experts (MoE)

MoE 是什么

把一个大 FFN 换成 N 个 FFN（专家）+ 一个路由器。每个 token 只被送进 top-k 个专家（比如 256 个里选 8 个）。

核心好处：参数和算力解耦。 你可以把专家数量加到很大（总参数暴涨 → 模型更强），但因为每个 token 只走 k 个专家，实际算的 FLOPs 几乎不变。所以 MoE 能”同样算力、更多参数、更好效果”，还训得更快、易于多卡并行。DeepSeek v3、Llama 4、Qwen 等高性能开源模型多是 MoE。

MoE 怎么变化（三个旋钮）

旋钮 选项 主流做法
路由函数 top-k / 哈希 / RL / 线性分配 几乎都用 token-choice top-k
专家规模 大专家少 vs 细粒度小专家多 + 共享专家 DeepSeek/Qwen 走”很多细专家 + 几个常开共享专家”
训练目标 RL / 随机扰动 / 启发式均衡损失 启发式负载均衡损失

训练 MoE 的两大难点

难点一：路由不可导。 “选哪个专家”是离散决策，没法直接求梯度。理论上该用 RL，但 RL 梯度方差大、复杂，实践中几乎没人用。主流是用 top-k 的 softmax 权重做近似 + 启发式。

难点二：负载不均。 如果大家都挤向少数热门专家，并行效率就崩了。解法是加一个均衡损失：某个专家被用得越多，就越压低它的权重，逼模型把 token 摊匀。DeepSeek v3 用”无辅助损失”的 per-expert 偏置在线调整。

其它工程细节：路由器用 fp32 + z-loss 保稳定；MoE 容易在小数据微调时过拟合；可用 upcycling（拿一个训好的稠密模型初始化 MoE）。

思考练习

  1. 用一句话解释 (Q·Kᵀ)·V = Q·(Kᵀ·V) 为什么把复杂度从 n² 降到 n。
  2. 线性注意力的”训练并行/推理线性”对偶，对长上下文推理有什么好处？（对照 L10 的 KV cache）
  3. MoE 为什么能”加参数不加算力”？这对训练成本意味着什么？
  4. 为什么 MoE 一定要加负载均衡损失？
