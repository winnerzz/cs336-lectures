CS336 学习台

第 13 讲 Data I (数据来源与版权)

预计用时： 90-150 分钟

一句话： 前面都在讲”给定数据怎么训”，这两讲讲”该用什么数据”。这一讲：数据从哪来（网页爬取、Wikipedia、GitHub、arXiv）、什么能合法用（版权与合理使用），以及著名训练数据集的演进史。

提示： 难度：概念为主、不吃 GPU，好读。数据是区分模型好坏最关键的一环，但各家最保密。

前置知识：这一讲默认你已经会（我从 0 给你补）

从 0 补上这一讲会用到的几个词：

  • 训练数据 / 语料 (corpus)：喂给模型学习的海量文本。预训练用上万亿 token（见 L09 的 token/参数比）。
  • 爬虫 (crawler)：自动程序，从一批种子网址出发，下载网页、再顺着超链接发现更多网页。
  • token：文本的最小单位（见 L01）。“15T tokens”就是 15 万亿个这种单位。
  • 训练的三个阶段（贯穿数据/对齐几讲）：
    • 预训练 (pre-training)：在海量较低质量文本上学（得到”base 模型”）。
    • 中训练 (mid-training)：再用较少的高质量数据强化能力。
    • 后训练 (post-training)：用对话/强化学习对齐（得到”instruct/chat 模型”，见 L15）。
    • 大趋势：从”大量低质” → “少量高质”。
  • 许可证 (license) / 版权 (copyright)：法律概念，下面正文展开。

数据不会从天上掉下来

核心教训：数据是要费力气搞的。 流程是”在线服务 → 爬取/转储 → 处理(转换/过滤/去重)“。数据是个长尾问题，随人力投入而扩展（不像架构、系统那样能靠算法一招解决）。而且开源模型连架构、训练流程都公开，唯独数据基本不说（怕竞争、怕版权诉讼）。

“在整个互联网上训练”其实没那么简单

理论上数据来自”公开万维网”，但实际有大量障碍： - 动态内容：很多网站是 app，URL 不变、要点按钮才出内容。 - 登录墙：Facebook/X/NYTimes 大量内容要登录甚至付费。 - 技术限制：robots.txt（自愿遵守）、Cloudflare 反爬、IP/国家封锁、限速。 - 法律限制：服务条款(ToS)可能禁止爬取；你可能没有复制网页用于训练的许可。 - 随时间推移，这些限制越来越严（各网站越来越不愿被爬）。 - 影子图书馆（LibGen、Sci-Hub）：技术上也是网络的一部分，但无视版权、绕过付费墙——法律上属于盗版侵权。

版权与合理使用（这一讲的重点）

几乎互联网上的一切都是有版权的（门槛极低，你的个人网站也自动有版权）。所以合法使用一份有版权作品，只有两条路：① 拿到许可证；② 主张”合理使用”。

许可证 (license)：本质是”承诺不起诉”。如 Creative Commons（Wikipedia、可汗学院等用）。很多公司直接花钱买数据许可（Google×Reddit、OpenAI×Shutterstock）。

合理使用 (fair use) 的四要素： 1. 使用的目的与性质（教育/转化性 优于 商业/复制性） 2. 原作的性质（事实性 优于 创作性） 3. 使用的比例（用片段 优于 用全文） 4. 对原作市场的影响

对语言模型的含义：训练第一步”复制数据”本身可能就构成侵权；但”训练出模型”应当是转化性的（远非复制粘贴）。判例（2025）：在合法获得的书上训练被判合理使用，但盗版拷贝不合法（Anthropic 为此和解付了 $1.5B）。这块法律仍在剧烈演变。

主要数据来源

来源 要点
Common Crawl 非营利，每月爬 30–50 亿网页，至今 3000 亿页。两种格式：WARC(原始 HTML)、WET(转好的文本)。HTML→文本的工具(trafilatura)选得好坏，直接影响下游效果
Wikipedia 6700 万篇、361 种语言；有官方定期 dump，不用爬。注意”数据投毒”：恶意编辑可在 dump 前注入
GitHub 4 亿+仓库；只能训练宽松许可(MIT/Apache)的；大量重复(fork)
arXiv ~300 万篇论文，有 S3 批量下载；作者可选版权或 CC

数据集演进史（一条主线：越来越会”过滤”）

数据集(年份) 关键思想
WebText (GPT-2) 用 Reddit ≥3 karma 的外链当”质量代理”
C4 (T5) 用手工规则清洗 Common Crawl（去标点不全的行、脏词、代码等）
The Pile 22 个高质量领域拼起来（社区众包）
RefinedWeb / FineWeb “网页数据就够了”，规则过滤 + MinHash 去重，FineWeb 达 15T tokens
Dolma 多源 + 语言/质量/毒性过滤 + Bloom filter 去重，3T tokens
DCLM 用质量分类器(fastText)过滤，把好数据(指令/ELI5)当正例、网页当负例
Nemotron-CC 觉得别人过滤太狠，用分类器集成 + LLM 改写合成数据保住更多 token
The Stack 代码数据集，只留宽松许可、去重
CommonPile 只用宽松许可数据能不能训出好模型？能，但缺 token 难竞争

大趋势：从”手工规则过滤” → “模型分类器过滤” → “用 LLM 合成/改写数据”。下一讲 L14 展开过滤和去重的具体算法。
