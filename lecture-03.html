第 3 讲 Architecture & Hyperparameters

预计用时： 120-180 分钟

一句话： 现在所有大模型的 Transformer 结构长得越来越像。这一讲把”现代标准配方”逐条讲清楚——pre-norm、RMSNorm、SwiGLU、RoPE、无 bias，以及那些”大家其实都用同一个值”的超参。这就是你在 A1 里要亲手实现的那个模型。

提示： 这一讲对 A1 极其重要：A1 让你实现的正是这里说的”现代变体”。建议边读边对照 A1 代码里的 cs336_basics。难度适中、纯概念，零基础认真过能学到很多。

前置知识：这一讲默认你已经会（我从 0 给你补）

这一讲讲的是”怎么改进 Transformer”，所以它默认你已经知道 Transformer 本身是怎么工作的（CS224N 内容）。如果不熟，先补下面三块，正文才看得懂。更基础的 Python/张量见 第 0 讲。

① 嵌入 (embedding)：把 token 变成一串数字 模型不能直接处理”词”，得先把每个 token 映射成一个固定长度的向量（一串数字，比如 4096 个），这个向量叫嵌入。意思相近的词，嵌入也相近。一句话进模型，就变成”一排向量”。

② 注意力 (attention)：让每个词”看”别的词（最核心，必须懂） Transformer 的灵魂。直觉：理解一个词要看上下文（“它”指代谁？）。注意力就是让每个位置去加权地参考序列里其他位置的信息。

机制（尽量白话）：每个词算出三个向量——Query（我想找什么）、Key（我能提供什么）、Value（我的实际内容）。一个词的 Query 和所有词的 Key 做点积，得到”我该多关注每个词”的分数；分数过一遍 softmax 变成权重（加起来=1）；再用这些权重把所有词的 Value 加权求和，就是这个词”看完上下文后”的新表示。本讲讲的 RoPE（位置）、GQA/MQA（KV 头）、QK-norm 全是在改这套机制的零件。

③ softmax：把一串数变成”和为 1 的概率” softmax([2, 1, 0]) 会输出像 [0.66, 0.24, 0.10] 这样——每个数取指数再归一化，大的更大、且全部加起来等于 1。注意力用它把”关注分数”变成”关注权重”；模型最后也用它把输出变成”下一个 token 的概率分布”。本讲的”稳定性技巧”(z-loss、logit soft-capping) 就是在防 softmax 的指数运算数值爆炸。

④ 前馈层 (FFN/MLP)：每个位置各自过一个小网络 注意力让词之间交换信息后，每个位置再单独过一个两层的全连接网络做”加工”。本讲讲的激活函数(SwiGLU)、d_ff = 4·d_model 都是在说这个 FFN 的细节。

一句话串起来：Transformer 一层 = 注意力(词间交流) + FFN(各自加工)，外面包着 残差 和 归一化。 这一讲就是逐个零件告诉你”现代模型把每个零件改成了什么、为什么”。

先补几个词（零基础向）

  • Transformer block（层）：模型由很多相同的”块”堆起来。每块里有两个主要部件：注意力(attention) 和 前馈网络(FFN/MLP)。
  • residual / 残差连接：把”输入”直接加到”该层输出”上（x + 层(x)），让信息和梯度有一条”高速公路”直通，深层网络才训得动。
  • normalization / 归一化 (Norm)：把一层的数值重新缩放到稳定范围，防止训练数值乱飞。常见 LayerNorm、RMSNorm。
  • activation / 激活函数：给网络加”非线性”的小函数（ReLU、GeLU、SwiGLU 等），否则多层等于一层。
  • position embedding / 位置编码：Transformer 本身不知道 token 的先后顺序，得额外告诉它”谁在第几位”。RoPE 是现在的主流做法。
  • bias / 偏置项：线性层 xW + b 里的 b。现代模型大多直接去掉它。
  • 超参 (hyperparameter)：训练前要你手动定的数字（层数、宽度、头数、词表大小等），不是学出来的。

学完你能

  1. 说清”原始 Transformer”和”现代变体”的差别（A1 实现的就是后者）。
  2. 逐条理解现代配方：pre-norm、RMSNorm、去 bias、门控激活(SwiGLU)、串行 vs 并行层。
  3. 理解 RoPE 为什么取代了正弦/绝对位置编码。
  4. 记住几个”共识超参”：d_ff ≈ 4·d_model（GLU 用 8/3）、头数×头维 = d_model、深宽比、词表大小。
  5. 了解稳定性技巧（z-loss、QK-norm、logit soft-capping）和注意力变体（GQA/MQA/MLA、滑窗）。

现代 Transformer = 原版改了 4 处

部件 原始 Transformer 现代变体（A1 实现）
Norm 位置 post-norm（块之后） pre-norm（块之前）
位置编码 正弦 sin/cos RoPE（旋转位置编码）
FFN 激活 ReLU SwiGLU
bias 偏置 有 没有（线性层和 norm 都去掉）

下面逐条解释”为什么”。

Pre-norm vs Post-norm（2024 年的唯一共识）

把归一化放在残差”主路”之外（pre-norm），几乎所有现代模型都这么做。

为什么 pre-norm 好？ 残差连接是深层网络的”信息高速公路”，你不想在主路上动手脚。post-norm 把 norm 卡在主路上，会扰动梯度、训练易出尖峰(spike)、得靠 warmup 救。pre-norm 把 norm 挪到支路，梯度传播更顺，能用更大的学习率训更大的网络。（少数例外如 OPT-350M 用了 post-norm，作者也没解释为啥。）

LayerNorm vs RMSNorm

  • LayerNorm：减均值、除标准差、再缩放（原版用）。
  • RMSNorm：不减均值、不加 bias，只用均方根归一化：y = x / sqrt(mean(x²) + ε) · γ（现代主流：LLaMA 系、PaLM、Chinchilla）。

为什么换 RMSNorm？ 它更省：少了求均值的运算、少了 bias 参数，效果却和 LayerNorm 一样好。

一个重要教训（贯穿全课）：FLOPs 不等于运行时间！RMSNorm 的 FLOPs 占比很小，但它的提速主要来自少搬数据(data movement)——又回到了 L02 的 memory-bound。所以”省参数 = 省搬运 = 省时间”。

去 bias 同理：省内存、还利于优化稳定，所以现代模型普遍去掉 bias 项。

激活函数与门控（SwiGLU）

激活函数有一大堆（ReLU/GeLU/Swish/各种 GLU）。现代共识是门控线性单元(GLU)，尤其 SwiGLU（LLaMA、PaLM、Mistral 等 2023 后基本都用）。

什么是”门控”？ 普通 FFN 是 FF(x) = activation(xW1)·W2。门控版多加一条线性支路当”闸门”：FF(x) = (activation(xW1) ⊗ xV)·W2，⊗ 是逐元素相乘。多了个参数矩阵 V，但效果稳定更好。

注意一个坑：门控版为了保持总参数量不变，会把中间维度 d_ff 缩到原来的 2/3，所以 GLU 模型的 d_ff ≈ (8/3)·d_model 而不是 4·d_model。A1 实现 SwiGLU 时这个 2/3 要记得。

串行 vs 并行层

标准块是串行：先算 attention，再算 FFN。少数模型（GPT-J、PaLM）让两者并行算（可共享 LayerNorm、融合 matmul 提速）。但现在主流仍是串行。

位置编码：为什么是 RoPE

Transformer 本身对顺序”无感”，要靠位置编码告诉它谁在第几位。演化：正弦 → 绝对 → 相对 → RoPE（2024+ 几乎全用）。

RoPE 的核心想法：理想的位置编码应该让注意力只依赖两个 token 的相对距离 (i−j)，与它们的绝对位置无关。怎么做到？利用一个数学事实：内积对旋转不变。于是把 query/key 向量的坐标两两配对，按”它在第几个位置”旋转相应角度。两个向量做注意力(内积)时，绝对旋转抵消，只剩相对角度差 → 自动只依赖相对位置。

实现上：在每次注意力计算时，对 query 和 key 乘一组 cos/sin 旋转矩阵。和正弦编码的区别是——RoPE 是乘性的、没有 cross term。A1 会让你实现这个。

共识超参（“大家其实都用同一个值”）

超参 标准值 备注
d_ff / d_model 4（GLU 用 8/3≈2.67） 几乎所有模型，少数例外如 T5 的 64 倍
头数 × 头维 = d_model（比例≈1） 大多遵守，谷歌部分模型例外
深宽比 d_model / 层数 约 100–200 太深难并行、延迟高；系统因素决定取值
词表大小 单语 30–50k，多语 100–250k 多语种才需要大词表

这一节的元教训：现代 LLM 的超参出奇地保守和一致。自学时不必纠结调参，照标准值来基本不会错。

正则化：还需要吗？

预训练数据上万亿 token、远多于参数，且只过一遍，理论上不太会过拟合。实践中：老模型常用 dropout，新模型（除 Qwen）基本只留 weight decay。

有意思的发现：LLM 用 weight decay 不是为了防过拟合，而是它和学习率(cosine 调度)相互作用、改善优化动态。

稳定性技巧（别训出会发散的模型）

不稳定多源于 softmax（指数运算易爆）。三个常用补丁： - z-loss：给输出 softmax 的归一化项加个正则，防止 logit 爆炸（PaLM、OLMo 2 用）。 - QK-norm：把 query、key 在进 softmax 前先做一次 norm（Gemma 2、Qwen3 用）。 - logit soft-capping：用 tanh 把 logit 压在一个上限内，防止数值飞掉。

注意力变体（省推理成本，和 L10 衔接）

大多数模型不怎么动注意力头，少数为省推理成本会改： - MQA / GQA / MLA：减少 Key/Value 头的数量 → 缩小 KV cache（详见 L10 笔记）。 - 滑动窗口 / 稀疏注意力：只看局部上下文，把注意力的平方复杂度降下来（GPT-OSS、Gemma4）。 - 现在的标准技巧：交错全局注意力和局部(滑窗)注意力（如每 4 层来一次全局）。
